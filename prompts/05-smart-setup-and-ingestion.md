# PROMPT 05 — Smart Setup, document ingestion, calendar and refresh

Read the contract/brief, approved contracts and current tests. Build an **end-to-end asynchronous or resumable** Smart Setup import, with realistic fallbacks, not a mock-only wizard.

- Inputs: first-approved calendar integration if credentials/scopes are approved; **ICS file import** fallback; human-readable one-line setup text; manual group CSV fallback; upload many individual files or ZIP with traversal/zip-bomb defenses; if browser folder selection is not cross-browser reliable, explicitly state browser constraints and support upload/refresh instead. Never promise background watching without it being tested.
- Implement an import manifest and Job model with queued/processing/partial/completed/failed/canceled states, progress by step, cancel/retry, dedup by normalized source ID/file hash and idempotent re-sync. Retain source-to-course mappings and import diagnostics. Changes generate reviewable proposals; never overwrite approved content silently.
- Parse **PDF, DOCX, PPTX, TXT/MD and common code** with page/slide/section provenance; DOC/PPT legacy best-effort only via safe conversion or clear unsupported feedback. Extract metadata and clean text; detect scanned PDFs and follow documented OCR policy (opt-in, local first where feasible, not blind OCR of everything). Preserve revisions and handle corrupted/encrypted/oversize/unsupported input with per-file statuses. No secret-bearing code ingestion into third-party model without consent.
- Calendar: normalize recurrence/timezones and daylight saving, map groups/events, preserve stable external IDs, de-dupe and test reschedules/cancellations; OAuth tokens encrypted + revocation if provider enabled; obey rate limits/backoff and webhook/sync permissions. Never create/change external calendar events in MVP.
- Build Smart Setup UI: calendar/import choice, material selection, clear pipeline progress and partial import report, editable candidate group/session mapping and **one final review/approve** screen (the roadmap generation step follows in Phase 06). Provide retry without losing selections.
- Tests: representative clean/corrupt/duplicate/incremental files, malformed ZIP, repeated ICS, timezone/DST, failed OCR, provider error, canceled job, partial success, idempotent refresh and auth isolation. Measure elapsed time/memory against a bounded sample corpus.

Deliver working import-to-database pipeline and sources panel; explicitly mark roadmap AI as next phase. Update docs/tests. Stop at checkpoint report and ask for Phase 06.
